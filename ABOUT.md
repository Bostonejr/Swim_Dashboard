##About the Swim Dashboard

I created a data analysis system for my swim team (African Sharks). 
After each training session, the collected performance data (time for each rep, stroke count, distance for underwaters, breakout distance, etc) is organized and structured into an excel sheet. 
Next, by designing my custom prompts for tools such as Claude AI, I perform a deep analysis and extract insights on each swimmer’s performance as well as the overall performance of the team. Using the react framework, I designed a centralized dashboard to neatly visualize the data findings. 

By using this dashboard my teammates have access to a personalized review of their performance for each training session, showing both their strengths and weakness. 
They get access to personalized recommendations on how to improve upon their weaknesses, that is the particular strokes to improve or the exact drills to practice with.
